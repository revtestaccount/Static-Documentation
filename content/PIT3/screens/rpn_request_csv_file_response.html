Note on ‘Conditional’ data items:

Where the data item is applicable, the field is mandatory and must be completed. Where the data item is not applicable, the field is not required to be completed. For example, the Pensions Tracing Number field is conditional. This means that if the employer operates an employer sponsored pension scheme, this field is mandatory.
