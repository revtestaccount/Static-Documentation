PAYE Modernisation Web Services – FAQ

The purpose of this FAQ is to help answer and resolve common questions and queries raised by users of the PIT (Public Interface Testing) environments. This FAQ page should be used in conjunction with the PAYE Modernisation Web Services documentation provided by Revenue.

TDM / Employers Certificate FAQ

What is the PIT3 environment?

PIT current version, also referred to as PIT3, is a representation of the live environment with functionality kept up to date with the functionality currently available in the live environment. The PIT3 (Public Interface Testing) environment provides developers and testers access to exclusive Revenue generated test data to verify the compatibility of their software packages with PAYE Modernisation.

What is the PIT4 environment?

PIT next version, also referred to as PIT4, contains upcoming functionality that is pertinent for developers to test their software ahead of the live release. The PIT4 (Public Interface Testing) environment provides developers and testers access to exclusive Revenue generated test data to verify the compatibility of their software packages with PAYE Modernisation.

What is a TDM (Test Data Management) certificate?

A TDM (Test Data Management) certificate will enable you to log in to the PIT Self Service Application where you can access and create new employer certificate(s).

What is an employer’s certificate for the PIT current version environment (PIT3)?

Employers in the PIT current version (PIT3) environment will have a certificate associated with them that will be of the form 9999XXXXX. The employer’s certificate is used to access ROS Payroll Reporting and to sign and submit payroll submissions and query requests.

What is an employer’s certificate for the PIT next version environment (PIT4)?

In the PIT next version (PIT4) environment, employers will have a certificate associated with them that will be of the form 8888XXXXX. The employer’s certificate is used to access ROS Payroll Reporting and to sign and submit payroll submissions and query requests.

Requesting new TDM and/or employer’s certificates?

Please only request replacement certificates when your current TDM or employer certificates are not functioning. New TDM (Test Data Management) certificates were issued beginning in early 2021 — PIT3 TDM since mid-March 2021 and PIT4 TDM since mid-June 2021.

If you have not received your new TDM certificates after the aforementioned dates, please raise a ticket on the PIT Help Desk requesting the same.

SOAP / REST Web Services

How do I build a REST endpoint?

REST endpoints follow the pattern:

https://{ENVIRONMENT}.ros.ie/paye-employers/v1/{API}/

Environments:

  • PIT3: softwaretest
  • PIT4: softwaretestnextversion

APIs:

  • payroll
  • rpn
  • returns_reconciliation
  • handshake

Common Errors

“Signature does not match signed content” error message?

Please follow the signature guide to build the signature correctly:

  • REST Request Authentication Guide (PIT3) PDF
  • REST Request Authentication Guide (PIT4) PDF
I have received a ‘BAS100’ error message?

Please check your ROS login URL — it should end with the correct table parameter:

https://{ENVIRONMENT}.ros.ie/oidc/login?client_id=payeselfservice_rp

Correct login URLs:

  • PIT3: https://softwaretest.ros.ie/oidc/login?client_id=payeselfservice_rp
  • PIT4: https://softwaretestnextversion.ros.ie/oidc/login?client_id=payeselfservice_rp

If that does not resolve the issue, ensure you are using the correct certificate for the environment:

  • PIT3 certificates are of the form 9999XXXXX
  • PIT4 certificates are of the form 8888XXXXX

Reporting Issues

How do I report an issue experienced while testing in the PIT environments?

Log in to the PIT Help Desk and click on the ‘New Ticket’ icon in the left toolbar. Please complete the query form with as much detail as possible.

You can also attach supporting files such as:

  • TDM Certificate (if applicable)
  • Employer’s Certificate
  • Request File
  • Response File
  • Log Files

Providing the PIT Help Desk Support Team with these supporting files in your initial query will greatly aid diagnosis of the issue.
